# CPQ Demo

A Logik.io + ServiceNow Quote Management demo front end, generated by the `/new-cpq-demo` Claude Code skill.

## Local development

```bash
npm install
npm run dev
```

Requires a `.env` file — see `.env.example`. Restart the dev server after changing `.env`.

## Structure

- `src/app/api/logik/*` — server-side proxy to the Logik.io API (keeps the token off the client)
- `src/app/api/servicenow/route.js` — server-side proxy to the ServiceNow Table API (keeps credentials off the client)
- `src/hooks/useConfigurator.js` — owns all Logik session state
- `src/components/ConfiguratorDemo.jsx` — the UI; customize this for your demo

## Deploying changes

Once connected to GitHub + Vercel (done automatically during setup), just ask Claude Code to "push this live" — it will commit, push, and redeploy.
